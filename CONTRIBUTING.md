# Contribuindo com honeypot-smtp-analyzer

Obrigado pelo interesse em colaborar.

1. Leia README.md, SECURITY.md e LICENSE.
2. Abra uma issue antes de propor mudancas significativas.
3. Inclua testes de regressao.
4. Preserve a compatibilidade do projeto.
5. Confira o GitHub Actions antes do merge.
6. Nao envie credenciais, tokens ou chaves privadas.
7. Reporte vulnerabilidades pelo canal em SECURITY.md.

Mudancas em autenticacao, criptografia e permissoes
exigem revisao adicional.
